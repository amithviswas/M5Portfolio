# Amith Viswas Reddy · M5 Portfolio

A BMW M-inspired personal portfolio for **Amith Viswas Reddy**, Associate Software Engineer at Accenture (Hyderabad), building AI apps, agents and automations.

**Live:** https://avr-portfolio-m5.netlify.app/
**Main portfolio:** https://portfolio-avr.netlify.app/

## Features
- Dark red-and-black performance theme with a short, skippable intro (click to skip)
- Projects shown up front, with detail modals, live demo and GitHub links
- Skills, certifications, achievements and a resume download
- Working contact form (sent via FormSubmit to my email)
- Light/dark toggle, reduced-motion support, and a hidden terminal easter egg (Ctrl/Cmd + X)

## Tech stack
Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, Lucide icons, Tone.js (optional UI sounds).

## Run locally
```bash
git clone https://github.com/amithviswas/M5Portfolio.git
cd M5Portfolio
npm install
npm run dev   # http://localhost:9002
```

## Build
```bash
npm run build && npm start
```
